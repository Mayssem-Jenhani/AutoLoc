# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

## Objectifs du projet
- Gérer le parc de véhicules de plusieurs agences
- Gérer les réservations et les locations des clients
- Offrir une API REST (Spring Boot) documentée avec Swagger

## Acteurs identifiés
- **Client** : consulte les véhicules, réserve, suit ses locations
- **Agent d'agence** : enregistre les locations et les retours de véhicules
- **Responsable d'agence** : supervise son agence, gère les agents et le parc
- **Administrateur** : gère les agences, les utilisateurs et la configuration globale

## Stack technique
Java 17, Spring Boot, Maven, MySQL, Postman, Git/GitHub
